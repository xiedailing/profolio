# Mia Hsieh — Portfolio

個人作品集網站。純 HTML / CSS,無 build 流程。設計稿來自 Figma(Portfolio / Desktop / 1440)。

## 檔案結構

- `index.html` — 頁面內容
- `styles.css` — 樣式(設計 token 在檔案最上方 `:root`)
- `assets/` — 專案圖片

## 本機預覽

直接用瀏覽器開啟 `index.html`,或在資料夾內執行:

```bash
npx serve .
```

## 部署

連結到 Vercel 後,每次 push 到 `main` 會自動部署。
